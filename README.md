# CyclePaths Web Frontend

This repository is part of the CyclePaths project. This is Team 7's capstone assignment for ICSI 499.

## How to Run:

First, make sure that the dependencies are installed by running:

```bash
npm i
```

Then you can run it locally by running:

```bash
npm run dev
```

You can then connect to the webpage by going to [http://localhost:5173](http://localhost:5173).

Finally, you can create a Podman Container by running: (Note that you may have to run `chmod +x ./scripts/build.sh` if your computer doesn't give you permission.)

```bash
./scripts/build.sh
```
